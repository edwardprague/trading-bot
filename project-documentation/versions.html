Versions

🔗
localhost:8080/versions

The lifecycle manager. Each version is a named profile bundling a set of Discovery-assigned parameters and its own regime allow-list state. The active version drives all BD backtests and RA runs.

  • Radio buttons — selecting sets that version as active immediately, persists to data/versions.json
  • Version numbering — sequential, auto-renumbers on deletion. New additions always increment from highest existing number.
  • Add Version — creates the next vN as an unassigned slot. Parameters are filled by assigning a Discovery trial.
  • Notes field — free-form per version, auto-saves on blur
  • Delete — removes version and triggers live rekey of versions.json, run buckets, and Discovery assignment records
⚠️
data/versions.json is the source of truth. Always commit to git after version changes.

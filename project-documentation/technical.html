Technical Setup

Environment
  • Working directory — ~/Documents/GitHub/trading-bot
  • Venv activation — source venv/bin/activate
Startup

Double-click start.command from Finder. Runs:

cd ~/Documents/GitHub/trading-bot
git pull
source venv/bin/activate
python3 server.py

Opens dashboard at http://localhost:8080

Run without creating new images:

GENERATE_DAILY_CHARTS=false python3 regime_analysis.py
Git
  • Repository — github.com/edwardprague/trading-bot
  • data/versions.json — tracked in git. Always commit after version changes.
  • data/ — otherwise gitignored (large OHLC parquets stay local)
  • Always git pull before starting a session on a new machine
  • start.command does git pull automatically on launch

Config & Labels

  • regime_labels.parquet — Per-fractal regime labels. Schema metadata carries macro_by_date JSON + tercile thresholds.
  • macro_by_date.json — Sidecar macro labels fallback
  • versions.json — Active-version id + per-version regime allow-lists + notes. Source of truth — tracked in git.
Environment Variables
Variable Default Effect
STRATEGY_VERSION v1 Routes strategy.py to strategy_vN.py
INSTRUMENT EURUSD One of EURUSD, GBPUSD, GBPJPY, etc.
INTERVAL 5m Bar interval (1m, 5m, 15m, 60m…)
TRADE_DIRECTION both both / long_only / short_only
EMA_SHORT 8 Short EMA period
EMA_MID 20 Mid EMA period
EMA_LONG 40 Long EMA period
RRR_RISK / RRR_REWARD 1 / 2 RRR ratio
FRACTAL_STOP_PIPS 15 Pip offset for fractal-based SL
MAX_DAILY_LOSSES 2 Daily-loss-stop threshold
BLOCKED_HOURS_UTC 4,5,6,8,10,11,14,17 UTC hours where entries are skipped
USE_EMA_FILTER true v2 EMA position filter toggle
EMA40_BUFFER_PIPS 5 Extra distance beyond EMA Long required
ALLOWED_MACRO_REGIMES Staircase Down,Strong Down Macro regime allow-list (empty = no gate)
ALLOWED_MICRO_REGIMES ranging-medium,ranging-wide Micro regime allow-list (empty = no gate)
APPLY_SLIPPAGE true Apply SL slippage in P&L
SL_SLIPPAGE_PIPS 1.0 Pips of adverse slippage on SL fills
SPREAD_PIPS 1.0 Round-trip spread cost per trade
GENERATE_DAILY_CHARTS true Per-day chart loop in regime_analysis.py

Route Method Purpose

/api/versions GET Return full versions.json store
/api/versions POST Add a new profile

/api/active_version GET Return currently-active profile dict
/api/active_version POST Switch the active profile
/run_regime_analysis POST Synchronous RA backtest re-run (~30–100s). Writes regime_state back to versions.json.
/results/<filename> GET Serve any file in results/
cTrader Integration
Code Generation

Click Create cBot on the BD. This calls cbot_templates.py which renders FractalBot_v{N}.cs. The generated file is overwritten on every generation — never edit it directly. All logic changes go in cbot_templates.py.

ℹ️
C# runs natively inside cTrader as a cBot. The Python Open API is an external connection not suitable for prop firm use.
